# Day-51-100-Days-challenge-in-cybersecurity-
## 🗓️ Day 51: SQL & Database Security

### 📑 Overview
Today’s focus was on **Structured Query Language (SQL)** and its pivotal role in both web development and cybersecurity. Understanding how data is stored, retrieved, and managed is essential for identifying server-side vulnerabilities.

### 🔑 Key Concepts
* **Role of SQL:** Acting as the communication bridge between the web backend and the database.
* **CRUD Operations:**
    * **Create (`INSERT`):** Adding new records.
    * **Read (`SELECT`):** Fetching specific data.
    * **Update (`UPDATE`):** Modifying existing entries.
    * **Delete (`DELETE`):** Removing data.
* **SQL Injection (SQLi):** * Exploiting unsanitized user inputs to manipulate queries.
    * **Example Payload:** `' OR '1'='1` used to bypass authentication logic.

### 🛡️ Cybersecurity Application
As an ethical hacker, SQL knowledge is used for:
1. **Enumeration:** Mapping database structures and table names.
2. **Exfiltration:** Extracting sensitive data (PII, credentials).
3. **Remediation:** Implementing prepared statements to ensure user input is treated as data, not executable code.
